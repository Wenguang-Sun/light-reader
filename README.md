# 轻读 · 轻量化本地 TXT 阅读器

一个纯前端实现、**零依赖、可离线运行**的本地小说阅读器。整个应用只有一个 `index.html` 文件，用浏览器打开即可使用。

## 使用方法

1. 双击打开 `index.html`（推荐使用 Chrome / Edge / Firefox）。
2. 点击右上角「**导入书籍**」选择本地的 `.txt` 文件，或直接把文件**拖进窗口**。
3. 点击书架上的书即可开始阅读。

## 功能

- **响应式分页**：按窗口宽度自动排版，当前页居中、左右对称露出相邻页，翻页动画轻快流畅。
- **排版可调**：字号、行距、段间距、字体（系统 / 宋体 / 黑体 / 楷体）、对齐方式、首行缩进、**页边距**（窄 / 标准 / 宽）。
- **拖动进度条**：底部进度条可拖动/点击，实时预览目标位置（百分比 + 章节），松手即跳转。
- **全文搜索**：右上角放大镜按钮，搜索当前文档内容，高亮所有匹配并支持上一个/下一个跳转；点击搜索结果可直接跳转到对应页面。
- **本地导入**：支持一次导入多个 TXT，自动识别 UTF-8 / GBK / GB18030，也可手动指定 Big5 等编码。
- **保存进度**：每本书的阅读位置（精确到段落）自动保存，重新打开即回到上次位置。
- **夜间模式**：一键切换，支持跟随系统。
- **书架**：封面、书名、体积、上次阅读时间与阅读进度一目了然。
- **章节目录**：自动识别「第X章 / 序章 / 楔子 / Chapter N」等中英文标题（并过滤正文误判），生成目录快速跳转。
- **阅读统计**：记录每本书的阅读时长、阅读速度（字/分）与预计剩余时间。
- **备份 / 迁移**：右上角「更多」菜单一键导出全部书籍 + 进度为 JSON 文件，可随时导入恢复。

## 操作

| 操作 | 方式 |
| --- | --- |
| 上一页 / 下一页 | 底部按钮、键盘 `←` `→` `空格` `PageUp/Down`、点击屏幕左右两侧 |
| 跳转位置 | 拖动 / 点击底部进度条 |
| 搜索内容 | 右上角放大镜按钮，输入关键词，`Enter`/`↑`/`↓` 切换匹配，点击结果跳转到对应页面 |
| 排版设置 | 右上角 `Aa`（含字号、行距、段间距、字体、对齐、首行缩进、页边距） |
| 目录 | 右上角列表图标 |
| 夜间模式 | 右上角月亮/太阳图标 |
| 备份 / 迁移 | 右上角「更多（⋯）」→ 导出备份 / 导入备份 |
| 返回书架 | 左上角返回箭头 |

## 数据存储

- 书籍正文与阅读进度保存在浏览器 **IndexedDB**（容量大，支持整本小说）；不可用时自动回退到 localStorage。
- 排版、主题等偏好保存在 **localStorage**。
- 「导出备份」生成的 JSON 文件可在不同浏览器 / 设备间迁移书籍与进度，解决本地数据无法跨浏览器同步的问题。

> 提示：数据按浏览器与本地文件来源隔离，换浏览器或移动文件位置后需重新导入。阅读过程中请勿清空浏览器站点数据。
